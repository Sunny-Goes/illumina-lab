# v0 plan — Walking skeleton (honk)

Milestone: [v0](https://github.com/Sunny-Goes/illumina-lab/milestone/1). Goal and exit criterion: [roadmap.md](roadmap.md#v0--walking-skeleton-honk). Decisions referenced as D*n*: [decisions.md](decisions.md).

**v0 simplifications** (explicit, revisited at v1):

- **No forge.** The honk pack and its four canary target manifests already exist in azimo's store; the lab points `ILLUMINA_STORE` at the submodule's store. The forge arrives with the first external codebase (v1).
- **No LangSmith dependency in facts.** Facts come from the run folder (`run.json`, evidence tree) and the driver's state dump. Tokens/cost join the schema in v2.

### PR 1 — Foundation: azimo submodule + dev plumbing

Items: azimo as pinned submodule; the venv convention documented (azimo's `.venv` is the execution env, the lab venv is separate — D9); pytest wiring with a `live` marker (azimo's convention); the gitignored `runs/` workspace and the single storage seam module (D15); smoke test that azimo imports from the submodule path.
Tests: offline smoke only.

### PR 2 — Canary store: models + loader + cross-check

As built (the review renamed things): `canaries/` package — `models.py` (`CanaryPointer`/`BugEntry`/`Canary`, D20), `loader.py` (structural validation, id-matches-path), `crosscheck.py` (pack/target exist, commit == snapshot_sha, bug files in scope, bug.win in the win table); `illumina_interface.py` (where the engine lives); the four honk entries authored in `illumina-training-set` under `canaries/honk/` (D19), pinned as a submodule. No hunk-presence validator (v1, D2).
Tests: schema, loader (synthetic + real submodule), cross-check (synthetic + real). Offline.

### PR 3 — Experiment core: ExperimentSpec, RunSpec, naming, ledger

As built: `experiment.py` (ExperimentSpec — name/canaries/wins/seeds/models, no fitness field (D4/D16); ModelConfig with azimo's role vocabulary; RunSpec; `load_experiment`); `naming.py` (spec hash = canonical spec + azimo pin + training-set pin; `exp-<sha8>-<name>-<date>-<n>` labels; `<label>-<canary>-<win>-s<k>` run ids); `orchestrator/` package — `matrix.py` (`expand`, `validate_experiment`), `ledger.py` (append-only events, dedupe by (spec, canary, win, seed)).
Tests: spec parsing/validation, hash stability and pin-move semantics, label/run-id minting, expansion order, ledger resume. Offline.

### PR 4 — Local runner + azimo driver

As built: `driver.py` (RunSpec in → `run_graph(run_id=…)` via azimo PR [#174](https://github.com/Sunny-Goes/azimo/pull/174), env stamped before the illumina import, tolerant state dump to `artifacts/<label>/<run_id>/state.json`, `error.json` + exit 1 on failure); `orchestrator/runner.py` (`Runner` protocol, `LocalRunner` — subprocess per beam with the PYTHONPATH bridge, `driver.log` tee, ledger events, concurrency cap with FIFO reap, per-run absolute deadline via `ILAB_RUN_TIMEOUT_S`, 0 disables). Engine pin moved to the #174 head.
Tests: env stamping, serializer leaves, state dump, error path (fake `illumina.cli`); runner mechanics against a fake driver (success/failure/timeout/cap); one live-gated real beam.

### PR 5 — Harvest + facts schema

As built: `facts.py` — `FactsRow`/`CoverageFacts` models, `harvest_run(label, run_id)` (state dump + runspec + provenance + azimo's run.json + ledger → one row; missing artifacts read as empty), `harvest_execution(label)` (idempotent per run_id), `read_facts()`. The driver stamps `provenance.json` (both pins) at spawn; `illumina_cache()` de-doubled (azimo's RUN_LABEL nests per execution).
Tests: row assembly from fabricated artifacts, failed-run rows, missing run.json tolerance, idempotent harvest. Offline.

### PR 6 — Judge + fitness

Items: ground-truth join (per bug: caught/missed + flagging stage), the coverage gate (no `llm_scan` record → run invalid; "site never read" annotation); the fitness plugin registry; the strict-recall plugin (D4).
Tests: fabricated facts → outcomes. Offline.

### PR 7 — `illumina-lab run` CLI + acceptance

Items: experiment-file loading (`experiments/*.json`, committed, hashed — D16); `illumina-lab run` (mint ids → ledger → runner pool → harvest → judge → fitness → scoreboard); README quickstart; the live-gated acceptance test on one honk canary — asserts run *validity* (coverage gate), never caught/missed (D16).
Tests: CLI plumbing offline; one live acceptance (provider key; docker optional — judgment is detection-level, D6).

## Settled questions

- Console script: `illumina-lab` (D17).
- Storage: local files behind one seam module; flat join-keyed records so a DB backend is a one-module swap; artifacts stay files under any backend (D15).
- Experiments are declarative data, tests are code (D16).
- 7 PRs, item-by-item review inside each.
